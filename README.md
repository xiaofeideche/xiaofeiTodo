# 晓飞待办

一个基于 HTML、CSS 和原生 JavaScript 的轻量级待办事项应用，数据保存在浏览器本地，无需后端即可运行。

## 功能特性

### 待办事项管理

- 添加待办事项（可同时设置截止日期）
- 支持按 Enter 键快速添加
- 查看待办事项列表
- 勾选复选框标记完成 / 取消完成（已完成项以删除线显示）
- 删除单个待办事项

### 截止时间与排序

- 为待办事项设置截止日期
- 按截止时间升序 / 降序排序（按钮箭头随排序方向切换）
- 已过期的待办事项以红色高亮显示并标注「已过期」

### 批量操作

- 一键全部完成
- 清空已完成事项

### 数据统计

- 底部实时显示「共 X 项，还剩 X 项没完成」

### 数据导出

- 一键将待办事项导出为文本文件（马克待办.txt）

### 数据持久化

- 使用 localStorage 保存数据，刷新页面后仍保留待办事项
- 首次访问时展示默认示例待办

### 紧急事项面板

- 自动展示截止时间在 24 小时内的未完成事项
- 按紧急程度排序
- 列表自动滚动展示

### 轮播图

- 5 张图片自动轮播（4 秒间隔）
- 支持左右按钮切换
- 支持指示点跳转

## 使用方法

直接用浏览器打开 `index.html` 即可使用，无需安装依赖或启动服务器。

## 技术栈

- HTML
- CSS
- 原生 JavaScript（无依赖、无需构建）
